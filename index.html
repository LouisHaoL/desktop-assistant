    插件是一段运行在主面板里的 JS 小扩展,通过 zda API 使用任务/设置/LLM/通知能力。插件与主程序同权限,只安装可信来源的插件。

      zda API 速查 
      zda.register({
  render(el, ctx)  { /* 往面板画 UI,可返回清理函数 */ },
  activate(ctx)    { /* 启用时可选项 */ },
  deactivate()     { /* 停用时可选项 */ },
});
ctx.invoke("task_list")          // 白名单命令:任务/设置/时间轴/llm_chat
ctx.storage.get/set(key, value)  // 插件私有 KV 存储
ctx.toast(title, body)           // 右上角通知
ctx.on("tasks-changed", fn)      // 监听事件(自动清理)
ctx.emit("tasks-changed")        // 广播事件
